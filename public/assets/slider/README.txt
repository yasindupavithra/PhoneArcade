HOME PAGE SLIDER — Auto images
=============================

1. Put your banner images in THIS folder:
   public/assets/slider/

   Supported: .png .jpg .jpeg .webp .gif

2. Run (or restart npm run dev — sync runs automatically):
   npm run slider:sync

3. Refresh the browser. All images in this folder will slide on the home page.

You can also put images directly in public/assets/ (root) — they are included too.
Do NOT put the logo here; keep logo in public/assets/logo/
